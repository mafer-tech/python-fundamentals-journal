# 🐍 Mis Inicios en Python

Este repositorio contiene una colección de scripts, ejercicios prácticos y notas de aprendizaje estructuradas durante mis primeros pasos aprendiendo programación en Python.

## 📂 Estructura del Repositorio

- **`01_basicos/`**: Declaración de variables, tipos de datos, operaciones matemáticas e ingreso de datos con `input()`.
- **`02_control_de_flujo/`**: Estructuras de decisión (`if / else`) y ciclos interactivos (`while`).
- **`03_estructuras_de_datos/`**: Creación, manipulación de listas y recorrido de elementos mediante ciclos `for`.
- **`04_funciones_y_modulos/`**: Modularización de lógica con bloques reutilizables `def`.
- **`05_proyectos_iniciales/`**: Integración de diccionarios, funciones y lectura/escritura de archivos `.json`.

## 🛠️ Tecnologías

- **Lenguaje:** Python 3.x
- **Formato de Persistencia:** JSON
- **Editor:** Visual Studio Code
